# Example assets

Sample models used by the three plugins' documentation + the browser demo.

- `data/` — STL / OBJ / PLY models (used by `maquette` docs)
- `data/gltf/` — glTF assets (used by `maquette-gltf` docs + demo)
- `scad/` — `.scad` source files (used by `maquette-scad` docs)
- `gltf/` — one-off Typst smoke tests for glTF features
- `doc-images/` — pre-rendered PNGs kept alongside docs sources
- `gallery_*` + `sss_bunny.png` — hero shots for the top README

The documentation files themselves live in [`../docs/`](../docs/) —
one PDF per plugin, built with `make docs`.
